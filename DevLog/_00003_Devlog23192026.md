The review of group anagrams went pretty well, although i felt the review was too close to actually completing it the first time. I still implemented the simple solution here which was to sort the strings and use the sorted string as the hash value as I still believe its more idiomatic and readable. However, I did come across a more optimal solution that used character frequencies for the 26 lowercase letters as the hash map key instead of sorting each string. Some implementations used an int[26] style frequency array together with a custom hash, while others converted the frequencies into a string key. It felt a bit over-engineered for this particular problem, but it was an interesting idea nonetheless. I might have a go at implementing it myself when I get some time in the future.

Finding all duplicates in an array was a bit of a humbling experience today with me having to get some help with it. A great learning experience though and you learn more from when you fail than when you succeed I guess. It opened up my mind to the possibilities of modifying the inputted array to store values and then returning it to its original form in memory constrained scenarios, which was a whole new way of thinking for me although i guess its specific to the situation whether that would be to overly complex to revers engineer.

Both the Two sum 2 and container with most water questions were review questions for me accidentally (whoooopsy) and at the same time they were both two pointer questions. They are a good reminder that usually when you are being asked for two values in someting sorted its likely a two pointer scenario and also a good intro to greedy algorithms and their limitations.

## Key takeaways  

- Questions are sneaky, check what they really want!
- O(1) space constraints should immediately make me question whether I can reuse the input data structure somehow.
- Negative marking is a useful technique to remember when values are restricted to a known range.
- Getting hints without the full solution is a good middle ground when completely stuck but it should be used with the utmost caution as its a slippery slope to letting skills decrease.
